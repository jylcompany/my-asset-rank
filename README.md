# 내자산순위 v2 — 공식 2025 분위값 반영

## 공식 자료
국가데이터처 「2025년 가계금융복지조사 결과」(2025-12-04 발표)를 기준으로 합니다.
2025년 3월 말 기준 평균 자산 5억 6,678만원, 평균 부채 9,534만원, 평균 순자산 4억 7,144만원입니다.

공식적으로 확인되는 순자산 분위 경계값:
- P50: 2억 3,860만원
- P60: 3억 3,050만원
- P70: 4억 6,180만원
- P80: 6억 9,380만원
- P90: 11억 20만원

또한 공식 발표에서 순자산 3억원 미만 가구는 57.0%, 10억원 이상 가구는 11.8%입니다.

## 계산 방식
- P50~P90: 공식 경계값 사이를 로그 보간하여 상위 비율을 추정합니다.
- P50 미만: 현재 코드에서는 공식 P10~P40 원표를 직접 내장하지 않았으므로 참고용 추정치로 표시합니다.
- P90 초과: 공식 P90 경계값을 기준으로 상위 꼬리를 부드럽게 추정합니다.
- 따라서 결과 화면에서 공식 경계값을 직접 사용할 수 있는 구간과 추정 구간을 구분합니다.

## 중요
사이트를 광고를 붙여 공개하기 전에 국가데이터처가 제공하는 2025 부록 통계표의 P10~P40 값까지 확인하여 `officialCutoffs`에 추가하는 것을 권장합니다.
