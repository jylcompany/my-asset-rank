## 계산 방법

P10~P90 사이에서는 인접한 공식 분위 경계값을 선형 보간해 참고용 백분위를 계산합니다. P10 아래와 P90 위는 공개된 경계값만으로 세부 백분위를 임의 추정하지 않고 각각 ‘하위 10% 구간’, ‘상위 10% 이내’로 표시합니다.

연령 비교는 가구주 연령대 평균·중위값 비교이며, 연령대별 백분위 순위가 아닙니다.

## 쿠팡파트너스

`public/index.html`의 상품 링크를 실제 쿠팡파트너스 추적 링크로 교체하면 제휴 수익화가 가능합니다. 현재는 일반 쿠팡 검색 링크를 기본값으로 넣어 기능이 끊기지 않게 했습니다.

## Cloudflare Workers

정적 파일은 `public/`에만 두고 Wrangler가 `./public`만 업로드하도록 구성했습니다. 따라서 `.git`, `.wrangler` 같은 저장소 내부 파일이 정적 자산으로 노출되지 않습니다.

배포:

```bash
npx wrangler deploy
```
